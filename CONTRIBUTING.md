# Contributing

Thanks for considering a contribution! This project is small and opinionated,
so a few notes before you open a PR.

## Ground rules

- **Small, focused changes.** One concern per PR.
- **Write clearly.** Code, commit messages, PR description.
- **Tests where they make sense.** Not every change needs a test, but the
  important ones do.
- **No AI-voice.** If your text reads like a brochure, rewrite it.

## Workflow

```bash
git checkout -b your-branch
# ... make changes ...
git commit -m "type: short imperative summary"
git push -u origin your-branch
```

Then open a PR. Use Conventional Commits if you can (`feat:`, `fix:`,
`docs:`, `chore:`).

## Reporting issues

Please include: what you expected, what happened, and how to reproduce.
Screenshots help.
