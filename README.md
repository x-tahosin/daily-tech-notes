# Daily Tech Notes

Short, lightly-edited markdown notes on AI, open-source, and tech news. One note every 12 hours, generated by `social-media-autopilot` from whatever story the bot picked to write about that cycle.

Each note has:

- **Front-matter** with date, SEO keyword, and category
- **One-line angle** explaining why the story matters
- **Key facts** the autopilot extracted (dates, company names, numbers)
- **TL;DR excerpt** from the long-form version on [dev.to/x-tahosin](https://dev.to/x-tahosin)
- **Cross-platform links** to the same story on Dev.to, Hashnode, X

## Why a repo for this

Two reasons. First, the GitHub contribution graph is a good daily-pulse signal: if it goes green, the pipeline is alive. Second, markdown is a clean archival format, better than scraping Dev.to or Hashnode after the fact.

## Structure

`notes/YYYY-MM-DD-slug.md`

That is it. No folders per category. One flat directory. You can search it with `grep` and feed it to an LLM for retro-summaries without any ceremony.
